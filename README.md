# repodemo2

This Vue.js application has one page that displays:

`This is Application Demo 2`

## Prerequisites (macOS and Linux)

Install Node.js and npm:

- Node.js `22.18+` (or `24.12+`)
- npm (bundled with Node.js)

### macOS (Homebrew)

```sh
brew install node
```

### Ubuntu/Debian Linux

```sh
sudo apt-get update
sudo apt-get install -y nodejs npm
```

## Install required packages

```sh
npm install
```

## Run tests

```sh
npm run test:unit -- --run
```

## Build production bundle (application binary assets)

```sh
npm run build
```

The compiled output is created in `dist/` and can be served on macOS or Linux using any static web server.
